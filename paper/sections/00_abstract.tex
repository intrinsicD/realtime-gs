\begin{abstract}
\noindent
Standard 3D Gaussian Splatting (3DGS) keeps every source photograph available for the whole
optimization.  Each iteration renders the current model against stored images, so for dense
multi-camera captures the raw RGB working set, not the model, dominates GPU memory, storage,
and bandwidth.  We propose to fit every input image once, offline, with a compact per-view 2D
Gaussian mixture, discard the images, and run all of 3D reconstruction against the frozen 2D
Gaussian fields.  These compact captures are small, analytic, and differentiable.  They can be
queried at arbitrary image points, which turns them into streaming supervision for 3DGS.

We first show that a standard 3DGS optimizer, initialized from random points or from a sparse
SfM point cloud, reconstructs a 3D Gaussian field from the 2D fields alone.

Rendering projects a 3D Gaussian field to per-view 2D Gaussians, and our captures are exactly
such projections.  A 3D initialization can therefore also be obtained by inverting the
projection.  We back-project each 2D Gaussian into an elongated 3D beam, intersect beams
across views in closed form, and fuse them by covariance intersection.  We analyze where the
naive inversion fails and address each failure with a renderer-aware covariance repair, a
fixed-topology refinement schedule, and a strict silhouette containment rule.

All components are implemented, deterministic on CPU, and covered by an audited evidence
ledger.  Current quantitative support is single-scene development evidence and is labelled as
such throughout.
\end{abstract}
