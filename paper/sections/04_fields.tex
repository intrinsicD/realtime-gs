\section{Compact 2D Gaussian Fields}
\label{sec:fields}

\subsection{Image model}
\label{sec:field-model}

A compact capture for view $v$ is a mixture of $N_v$ anisotropic 2D Gaussians with an exact,
self-describing evaluation semantics.  The capture is a frozen renderer, not a loose point
set.  Component $j$ carries a mean $\bm{m}_j \in \Omega_v$ and a rotated anisotropic
covariance
\begin{equation}
  C_j \;=\; R(\theta_j)\,\diag\!\big(s_{j,1}^2,\, s_{j,2}^2\big)\,R(\theta_j)\T
  \;+\; \sigma_{f,j}^2\, I_2
  \label{eq:cov2d}
\end{equation}
with scales $s_j$, rotation $\theta_j$, and an optional isotropic filter variance
$\sigma_{f,j}^2$ acting as an anti-aliasing floor.  It further carries a non-negative
amplitude $a_j \ge 0$, a base color $\bm{c}_j \in \R^3$ that is intentionally unbounded, and
optionally a local affine color model $\bm{c}_j(\bm{x}) = \bm{c}_j + G_j\T(\bm{x} -
\bm{m}_j)$ with per-component gradients $G_j \in \R^{2\times 3}$.  With the unnormalized
kernel
$w_j(\bm{x}) = a_j \exp\!\big({-\tfrac12 (\bm{x}-\bm{m}_j)\T C_j^{-1} (\bm{x}-\bm{m}_j)}\big)$
truncated at a $3\sigma$ support box, the field renders by normalized blending as
\begin{equation}
  \field_v(\bm{x})
  \;=\;
  \frac{\sum_j w_j(\bm{x})\, \bm{c}_j(\bm{x})}
       {\varepsilon + \sum_j w_j(\bm{x})},
  \qquad \varepsilon = 10^{-8}.
  \label{eq:field}
\end{equation}
Every constant in \cref{eq:cov2d,eq:field}, including the cutoff, $\varepsilon$, the blend
mode, the fit window, and the producer version and configuration digests, is stored inside
the capture container.  A consumer therefore reproduces the fitted image bit-consistently
without any out-of-band convention.\evidence{src/rtgs/core/observation2d.py}

\paragraph{Gauge freedom.}
The normalized blend makes the pair $(a_j, \bm{c}_j)$ non-identifiable up to
product-preserving rescalings.  Transformations that leave every rendered color unchanged
can still change downstream algorithms that read raw amplitudes.  We measured exactly this
failure mode.  In a frozen audit, 54 product-preserving re-gaugings left all source renders
equivalent while materially changing coverage and retention of two downstream
lifters.\evidence{ara/logic/claims.md C15}  The rule in this paper is therefore that
downstream stages consume rendered quantities, that is, field queries and normalized
weights, or fix an explicit gauge.  No stage may attach physical meaning to a raw
amplitude.  In particular a fitted 2D amplitude is not a 3D opacity, which matters again in
\cref{sec:refinement}.

\subsection{Fitting and storage}
\label{sec:fitting}

The capture stage fits each view independently by differentiable 2D splatting in the style
of GaussianImage \citep{zhang2024_gaussianimage}.  The fits are independent per image and
can run in parallel across views.  Our implementation provides two interchangeable
backends, a native accumulated-splatting fitter and a structured fitter with the affine
color basis of \cref{eq:field}.  The fit is a standard robust photometric minimization over
all component parameters with a fixed component budget.  Masked captures restrict the fit
window to the subject.  After fitting, the field is frozen and every later stage treats it
as an immutable measurement.

Captures serialize to a small container, one file per view, holding the parameter arrays
plus integrity digests.  The current capture format caps at $168\,\mathrm{kB}$ per
view.\evidence{benchmarks/results/20260725_init_value_program_PREREG.md}  For the
development scene used throughout (\cref{sec:exp-setup}) the native resolution is
$5328 \times 4608$.  One raw float32 frame is therefore $294.6$~MB and one 8-bit frame
$73.7$~MB, against at most $0.168$~MB per capture.  This is a $440\times$ (8-bit) to
$1750\times$ (float32) reduction of the static input working set.  These numbers are format
arithmetic.  The measured process peaks of \cref{sec:memory} decide the actual memory
result.

Conventional codecs decode to full frames, so supervision from a JPEG still costs a dense
RGB tensor in device memory.  The compact capture is competitive on bytes and at the same
time its evaluation is a closed-form differentiable function at exactly the sample
locations the optimizer requests.  This property enables the streaming supervision of
\cref{sec:reconstruction}.
