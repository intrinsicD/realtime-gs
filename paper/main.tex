% Working draft.

% Storyline: per-view 2D Gaussian fields replace the images. A standard 3DGS
% optimizer reconstructs from the fields alone (initialized from random
% points or SfM). Memory is measured under a controlled protocol. Because
% rendering projects 3D Gaussians to 2D Gaussians, initialization can also
% be obtained by inverting the projection (tomographic initialization). The
% naive inversion fails in identifiable ways, which the carrier refinement
% addresses. Experiments show the full pipeline and end with the ablations.
