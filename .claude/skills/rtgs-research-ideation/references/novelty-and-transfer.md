# Novelty and transfer tests

## Novelty classes

- `N0`: routine tuning, engineering, or restatement.
- `N1`: known method transferred to the repository with no new relationship.
- `N2`: known components combined around a specific unresolved mechanism.
- `N3`: new relation, operator, observable, representation, or evidence program that changes what
  can be tested.
- `N4`: new problem grammar or characterization that makes a different class of claims possible.
- Add `-T` when novelty depends on a cross-domain mechanism transfer.

The class is provisional until the prior-art audit.

## Transformation tests

Apply every test:

1. **A+B:** Does the candidate reduce to two named existing techniques connected in the obvious
   way?
2. **Subtraction:** After removing fashionable machinery, is a falsifiable delta left?
3. **Grammar:** Does it change the primitive, admissible operation, information boundary,
   objective, or evidence?
4. **Prediction:** Does it predict an outcome that current formulations do not?
5. **Necessity:** Is the new object/mechanism required for the prediction?
6. **Compression:** Does one mechanism explain multiple existing anomalies or failures?

Downgrade candidates that fail. A useful `N1` or `N2` is better than inflated novelty.

## Cross-domain transfer test

For each donor mechanism:

- map donor objects and operations to recipient objects and operations;
- identify what is structurally preserved;
- state at least one broken correspondence;
- name the invention needed to bridge it;
- compare against the strongest native baseline;
- derive a recipient-specific prediction;
- design a counter-analogy that would show the transfer is only metaphor.

Then apply:

- **Terminology removal:** does the idea remain meaningful without donor jargon?
- **Structural map:** are relations/operators preserved, not only object names?
- **Causal preservation:** does the donor mechanism act through the same causal dependency?
- **Historical obviousness:** would a field expert have made this transfer routinely?
- **Adoption barrier:** what prior limitation prevented the transfer, and what changed?

A black-box donor algorithm with no preserved mechanism is an implementation candidate, not a
transformational transfer.
