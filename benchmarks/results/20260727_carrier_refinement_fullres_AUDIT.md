## Scope correction

The machine audit's disposition string
`REJECT_PROPOSED_CARRIER_SCHEDULE_ON_FRAME00008` is too broad. The executed treatment contains
only 30 warm-up, 40 clone, 30 higher-SH, and 60 standard updates, followed post hoc by 40 recovery
updates. It has no convergence stopping rule. It also saves only arm initialization/final images,
not the covariance-, opacity-, appearance-, warm-up-, or clone-wave states. Therefore the evidence
rejects that short treatment only; it cannot reject the iterative until-convergence process in
ADR-002. The numeric audit and invariant findings remain valid.

## Critical finding: immature parent endpoints

Nine of the 160-update parent endpoints were measured immediately after a non-empty density
operation at update 160:

`beam-standard`, `carrier-schedule`, `carrier-schedule-clone`, `no-covariance`, `no-opacity`,
`split-immediately`, `random-rgb`, `random-jpeg-q50`, and `means-only`.

Their final operation created between 622 and 1,877 net new rows, and their appended newborns
received zero
subsequent updates. This invalidates those parent values as mature-model comparisons. It does not
invalidate the saved computation or the earlier fixed-track repair mechanics.

Terminology erratum: the frozen recovery protocol calls the net-growth counts “newborns.” The
machine audit keeps the quantities separate; for example, `beam-standard` appended 899 newborns,
pruned/replaced other rows, and therefore grew by a net 622. This wording error does not change the
recovery trigger or any metric.

The remediation was frozen separately after the finding: reload every optimized parent PLY by
hash and apply exactly 40 fixed-topology native-resolution updates to all twelve optimized arms.
Primitive counts remain exact. The recovery uses a fresh Adam optimizer because parent optimizer
state was not serialized, so it is a uniform polish segment rather than an exact continuation.
The original parent bundle remains untouched.

## Repeatability

The complete parent matrix was replayed independently. CUDA density decisions are not bit
deterministic: the largest foreground-PSNR difference is 0.136135 dB and the largest final-count
difference is 85. These differences do not change any central disposition, but parent topology
results should not be described as exact replay.

The complete fixed-topology recovery was also replayed. All primitive counts match and the largest
foreground-PSNR difference is 0.0000324 dB. This is strong arithmetic repeatability for the saved
recovery boundary, subject to the explicit optimizer-restart limitation.

## Audit verdict

The implementation is testable and the experimental bundle is internally coherent after the
recovery correction. The tested short schedule should remain opt-in and must not become a default.
Covariance repair should not be retained as a presumed-beneficial phase merely because its own
loss improves. The intended ADR process still requires an instrumented convergence run. A future
paper test additionally needs non-outcome-exposed scenes, multiple paired seeds, recovery after
the final density event, actual SfM baselines, and a compact-only optimization path before the
main sufficiency or systems claims can be tested.
