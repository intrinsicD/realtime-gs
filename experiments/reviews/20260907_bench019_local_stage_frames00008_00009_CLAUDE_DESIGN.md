Scope: prospective design only. No outcomes, images, masks or code were seen; nothing below claims execution or test results.

**Findings (5)**

1. **Decision-policy gates are unsatisfiable or degenerate by construction; pre-declare that.** `minimum_capture_groups: 3` cannot be met with one capture; with 3 families, Spearman ≥ 0.8 is just "exact rank match" (possible values ±1, ±0.5), LOFO leaves a 2-family binary, and a 1000-replicate bootstrap over 3 points has no meaning. With `missing_policy: fail_closed`, the surrogate verdict is a deterministic "fail". Minimal fix: set the surrogate verdict field to `not_evaluated_insufficient_scope` at freeze time and keep only the per-frame paired reporting as the deliverable, so a forced fail is never read as evidence against the hypothesis. Also relabel frame_00009 (consecutive frame, same rig, same view IDs) as *within-capture consistency*, not "replication"; it is a dependent unit and should not count toward `minimum_frames`.

2. **Primary comparison is capacity-compressed and under-replicated; fix the interpretation rule now.** 256 Gaussians, SH0, no densification, 1000 iterations on a fabric stage will floor all families at low PSNR; a 0.25 dB materiality gap may be undetectable regardless of Stage-1 fidelity. With 3 seeds × 3 held-out views per frame, no distributional test is credible. Pre-register: (a) materiality = paired difference ≥ 0.25 dB with the same sign in all 3 seeds *and* both frames, else "not detectable at this capacity"; (b) report seed-to-seed spread per cell alongside differences so the 0.25 dB floor is judged against noise; (c) add to `claim_boundary` that a null ranking is capacity-bounded, not evidence of equivalence.

3. **Initializer fallback is an uncontrolled confound between families.** `unsupported_anchor_policy` retains a bounded-midpoint fallback, `min_neighbor_views: 2` on 8 sources with source exclusion, and the normalized family's "support is not alpha" means its supported-anchor set can differ systematically. If fallback fractions differ by family, the downstream ranking measures support semantics, not fitting fidelity. Without tuning, freeze a descriptive flag: if any family's fallback fraction exceeds a pre-set value or differs from another family by more than a pre-set delta (choose now, e.g. 10 points), mark the frame's ranking "initializer-dominated". Also confirm that the midpoint bounds (with `bounds_hint: null`) derive from per-frame calibration/mask geometry, identical for all three families, not from each family's field.

4. **AA replay coverage and failure semantics.** Replay covers only native_additive/seed 19001 with a 0.05 dB absolute tolerance on a gsplat CUDA backward path where atomic accumulation can be non-bit-reproducible; a failure invalidates conclusions for StructSplat families that have no replay at all. Minimal corrections: run the AA pair as the *first* downstream cells so nondeterminism is exposed before the budget is spent; record all determinism-related settings in the resolved dataclasses; add one StructSplat contained replay cell (cheapest extension, covers the mask-containment code path). Keep the no-tolerance-tuning rule.

5. **Evaluation and seed specification gaps to close in the resolved configs.** (a) Alpha-IoU binarization threshold of predicted alpha is unspecified; (b) held-out PSNR domain is unspecified — full undistorted downscaled frame vs training crop, soft vs thresholded foreground mask, 8-bit-quantized vs float, clamping; (c) exterior-leakage denominator (all exterior pixels vs crop exterior) is ambiguous; (d) seed hygiene: the Stage-1 rule yields 19001–19003 for frame 0 / views 1–3, numerically colliding with downstream seeds, and predictor seed equals bootstrap seed (19019). Harmless if RNG streams are separate, but rename to keep audit trails unambiguous.

Practicality: 48 Stage-1 fits (512 × 1000 it.) plus 24 downstream workers + replay cells is well within a shared RTX 4090 budget; resource protocol, contention handling, two-phase gating, and the explicit source/export-drift measurement are appropriate and need no change.
